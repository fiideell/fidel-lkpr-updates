# First release checklist — scenery 3.0.1

Repository: https://github.com/fiideell/fidel-lkpr-updates

1. Open the repository and choose **Releases** → **Draft a new release**.
2. Create tag: `v3.0.1`
3. Release title: `Fidel LKPR Live 3.0.1`
4. Attach the original scenery ZIP:
   `zzz_fidel-lkpr-live-tailstrike-edition.zip`
5. Release notes can start with:
   `Initial updater-supported release of Fidel LKPR Live 3.0.1.`
6. Publish the release.

Important:
- Keep the asset filename exact; the updater looks for that exact name.
- The package manifest inside the ZIP must say `package_version: 3.0.1`.
- Do not mark the release as a pre-release.
