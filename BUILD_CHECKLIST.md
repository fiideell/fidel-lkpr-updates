# Fidel LKPR Updater 2.0 build checklist

1. Extract this ZIP.
2. Run `build_windows.bat` on Windows.
3. Confirm `dist\FidelLKPRUpdater.exe` launches and shows the supplied LKPR header.
4. Test both English and Čeština; the selected language should persist after restart.
5. Confirm the Community path remains saved.
6. Check GitHub release detection and install only when a real newer scenery release exists.
7. Keep the previous scenery backup until the new scenery has been tested in MSFS.
